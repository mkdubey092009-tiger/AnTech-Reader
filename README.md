# OpenAcrobat

A free, open-source Python desktop PDF reader, annotator, converter, and organizer inspired by Adobe Acrobat Reader & Acrobat Pro.

## Features
- **View & Read:** Thumbnail sidebar, zoom, Dark Mode night reader, full-text search with yellow bounding boxes, and offline **Read Aloud (TTS)**.
- **Annotate:** Drag-to-highlight text, add sticky note comments, insert free-text boxes, and draw freehand ink strokes.
- **Fill & Sign:** Built-in signature drawing pad or image signature stamping.
- **Organize Pages:** Rotate, reorder, delete, merge multiple PDFs, and split/extract page ranges.
- **Convert & Create:** Export PDF to Word (`.docx`), export PDF pages to PNG images, and create PDFs from images.
- **Compress & Security:** Compress PDF size and lock PDFs with **AES-256 encryption**.
- **OCR:** Extract text from regular or scanned PDFs (supports Tesseract OCR).

```bash
git clone [https://github.com/YOUR_USERNAME/OpenAcrobat.git](https://github.com/YOUR_USERNAME/OpenAcrobat.git)
