# AnTech Reader

A free, open-source Android PDF reader, annotator, signer, and organizer built in Python.

## Features
- **View & Read:** Smooth page viewer, zoom controls, Dark Mode night reader, text search, and Read Aloud (TTS).
- **Annotate:** Drag-to-highlight, insert text, and draw freehand ink strokes.
- **Fill & Sign:** Built-in touch signature pad to sign and stamp PDFs.
- **Organize & Convert:** Rotate pages, delete pages, merge multiple PDFs, split/extract page ranges, convert images to PDF, and password-protect PDFs.
